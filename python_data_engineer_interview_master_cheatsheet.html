Senior follow-up questions — easy interview answers

QUESTIONS FROM PDFANSWERS EXPANDED

What happens with billions of rows?

I would not collect them into Python memory. I would move the same logic to Spark/Databricks: explicit schema with from_json, column expressions for cleaning/filtering, then distributed groupBy. I would partition appropriately, avoid Python UDFs where native Spark functions exist, and monitor skew/shuffle volume.

How do you handle schema evolution?

Keep an explicit contract for required fields, tolerate optional additive fields, quarantine incompatible records, version schemas where necessary, and add tests/metrics for unexpected fields or type changes. In a lakehouse, evolve intentionally rather than blindly accepting every change.

How do you monitor bad records?

Do not silently lose them. Count rejected records, capture reason codes, write bad payloads to a quarantine/dead-letter location where appropriate, and alert when error rate breaches a threshold.

How would you test this?

Unit-test valid, blank, malformed, missing-key, null, duplicate and mixed-case inputs; test exact aggregate output; then integration-test file/topic input and output contracts. Add scale/performance tests separately.

How do you make it idempotent?

Use a stable business/event key and deterministic transformations. On retries, merge/upsert or overwrite the intended partition/batch rather than blindly append duplicates. Record processed batch/checkpoint metadata.

Why is this O(n)?

Each input record is visited once. Dictionary/set lookup and update are average O(1), so the total is O(n). Space depends on how many distinct keys/IDs I retain.

2. Two Sum complement map

MEMORISE
Skeleton
seen = {}

for i, x in enumerate(nums):
    needed = target - x

    if needed in seen:
        return [seen[needed], i]

    seen[x] = i
seen[x] = i means: “I have seen value x; remember its index i.” Later, if that value is the complement you need, you can return its earlier index.

3. Two pointers

MEMORISE
Skeleton
left, right = 0, len(nums) - 1

while left < right:
    total = nums[left] + nums[right]

    if total == target:
        return [left, right]
    elif total < target:
        left += 1
    else:
        right -= 1
This pair-sum version assumes the array is sorted.

4. Sliding window

MEMORISE SHAPE
Fixed-size example
k = 3
window_sum = sum(nums[:k])
best = window_sum

for right in range(k, len(nums)):
    window_sum += nums[right]
    window_sum -= nums[right - k]
    best = max(best, window_sum)
Signal word: contiguous. Instead of recomputing every window from scratch, add the new right item and remove the old left item.

5. Prefix sum

MEMORISE
Skeleton
prefix = [0]

for x in nums:
    prefix.append(prefix[-1] + x)

# inclusive range left..right
range_sum = prefix[right + 1] - prefix[left]

6. Stack

MEMORISE
Valid parentheses
pairs = {")":"(", "]":"[", "}":"{"}

7. Binary search

MEMORISE
Skeleton
lo, hi = 0, len(nums) - 1

while lo <= hi:
    mid = (lo + hi) // 2

    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        lo = mid + 1
    else:
        hi = mid - 1

return -1

8. Merge intervals

MEMORISE SHAPE
Skeleton
intervals.sort(key=lambda x: x[0])
merged = []

for start, end in intervals:
    if not merged or start > merged[-1][1]:
        merged.append([start, end])
    else:
        merged[-1][1] = max(merged[-1][1], end)

return merged

MASTER SCRIPT 1 — Event-log / JSON processing

BASED ON YOUR PDF EXAMPLEEXPANDED
Covers string cleaning, JSON parsing, safe access, nested data, dedupe, aggregation, timestamps, bad-record metrics and JSON output.
Full script
import json
from collections import defaultdict
from datetime import datetime

def process_events(raw_lines):
    project_counts = defaultdict(int)
    seen_ids = set()
    stats = {
        "input": 0,
        "blank": 0,
        "malformed": 0,
        "duplicate": 0,
        "accepted": 0
    }

    for line in raw_lines:
        stats["input"] += 1

        # 1) Clean string
        line = line.strip()
        if not line:
            stats["blank"] += 1
            continue

        # 2) Parse JSON safely
        try:
            event = json.loads(line)
        except json.JSONDecodeError:
            stats["malformed"] += 1
            continue

        # 3) Defensive field access + normalize
        event_id = event.get("id")
        event_type = event.get("type", "").strip().lower()
        status = event.get("status", "").strip().lower()
        project = event.get("project", "unknown")

        # Nested JSON example
        actor_id = event.get("actor", {}).get("id")

        # 4) Deduplicate when ID exists
        if event_id is not None:
            if event_id in seen_ids:
                stats["duplicate"] += 1
                continue
            seen_ids.add(event_id)

        # 5) Filter business condition
        if event_type != "issue_created" or status != "success":
            continue

        # 6) Optional timestamp parsing
        created_at = event.get("created_at")
        created_epoch = None
        if created_at:
            try:
                created_epoch = int(
                    datetime.fromisoformat(
                        created_at.replace("Z", "+00:00")
                    ).timestamp()
                )
            except ValueError:
                pass

        # 7) Aggregate
        project_counts[project] += 1
        stats["accepted"] += 1

        # Variables show how flattened output could look
        flattened_record = {
            "id": event_id,
            "project": project,
            "actor_id": actor_id,
            "created_epoch": created_epoch
        }

    # 8) Serialize final result
    result = {
        "project_counts": dict(project_counts),
        "stats": stats
    }
    return json.dumps(result, indent=2)


raw_input = [
    '{"id":1,"type":"Issue_Created","status":"SUCCESS","project":"JIRA","actor":{"id":"u1"},"created_at":"2026-08-10T00:00:00Z"}',
    '{"id":2,"type":"issue_created","status":"success","project":"CONFLUENCE","actor":{"id":"u2"}}',
    '{"id":2,"type":"issue_created","status":"success","project":"CONFLUENCE"}',
    '{"id":3,"type":"issue_updated","status":"success","project":"JIRA"}',
    ' malformed json ',
    ''
]

print(process_events(raw_input))
Say aloud: “This is one pass, so O(n) time. The set and dictionary use memory proportional to unique IDs/projects. At large scale I would translate this to Spark DataFrame transformations, explicit schema, distributed aggregation and a quarantine path for bad records.”

from collections import Counter
import heapq


# 1) FREQUENCY DICTIONARY
def frequency(nums):
    count = {}
    for x in nums:
        count[x] = count.get(x, 0) + 1
    return count


# 2) FIRST UNIQUE CHARACTER
def first_unique(s):
    count = Counter(s)
    for i, ch in enumerate(s):
        if count[ch] == 1:
            return i
    return -1


# 3) CONTAINS DUPLICATE — SET
def contains_duplicate(nums):
    seen = set()
    for x in nums:
        if x in seen:
            return True
        seen.add(x)
    return False


# 4) TWO SUM — DICTIONARY
def two_sum(nums, target):
    seen = {}

    for i, x in enumerate(nums):
        needed = target - x

        if needed in seen:
            return [seen[needed], i]

        seen[x] = i

    return []


# 5) TWO POINTERS — SORTED ARRAY
def pair_sum_sorted(nums, target):
    left, right = 0, len(nums) - 1

    while left < right:
        total = nums[left] + nums[right]

        if total == target:
            return [left, right]
        elif total < target:
            left += 1
        else:
            right -= 1

    return []


# 6) FIXED SLIDING WINDOW
def max_sum_k(nums, k):
    if k <= 0 or k > len(nums):
        return None

    window_sum = sum(nums[:k])
    best = window_sum

    for right in range(k, len(nums)):
        window_sum += nums[right]
        window_sum -= nums[right - k]
        best = max(best, window_sum)

    return best


# 7) PREFIX SUM + RANGE QUERY
def build_prefix(nums):
    prefix = [0]
    for x in nums:
        prefix.append(prefix[-1] + x)
    return prefix

def range_sum(prefix, left, right):
    return prefix[right + 1] - prefix[left]


# 8) VALID PARENTHESES — STACK
def valid_parentheses(s):
    pairs = {")":"(", "]":"[", "}":"{"}
    stack = []

    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False

    return not stack


# 9) BINARY SEARCH
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1

    while lo <= hi:
        mid = (lo + hi) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1

    return -1


# 10) MERGE INTERVALS
def merge_intervals(intervals):
    intervals.sort(key=lambda x: x[0])
    merged = []

    for start, end in intervals:
        if not merged or start > merged[-1][1]:
            merged.append([start, end])
        else:
            merged[-1][1] = max(merged[-1][1], end)

    return merged


# 11) TOP K — HEAP
def top_k(nums, k):
    return heapq.nlargest(k, nums)

Pro tips I added

ADDED
  • Prefer native/vectorized pandas or Spark expressions over row-wise Python loops/UDFs for large tabular data.
  • For joins, validate key uniqueness before assuming one-to-one; accidental many-to-many joins can explode row counts.
  • For dedupe, define which record wins (latest timestamp, highest version, trusted source) rather than calling drop_duplicates() blindly.
  • For windows, always make the ordering explicit before lag, lead, cumulative or rolling calculations.
  • For production ingestion, distinguish bad syntax, bad schema, and bad business data; they usually need different handling.
  • In an interview, a clear O(n) solution with tests and explanation is usually stronger than an obscure “clever” solution.
